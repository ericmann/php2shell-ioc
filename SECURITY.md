# Security

## Reporting a problem with this tool

If you find a way the script could be made to write files, open network
connections, execute code it shouldn't, leak secrets in its output, or be
abused when run as root against a hostile filesystem, please report it
privately through GitHub's **"Report a vulnerability"** (Security tab), not a
public issue.

## Reporting a PHP vulnerability

This project doesn't handle PHP vulnerabilities. Report those to the PHP
security team: https://github.com/php/php-src/security

## If the script finds something

This is a triage tool. A FLAG means "investigate", not "confirmed breach". See
the README's "Reading the output" section and [docs/indicators.md](docs/indicators.md).
